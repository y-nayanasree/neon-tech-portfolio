
# Neon Tech Portfolio

A responsive personal portfolio website with a modern cyberpunk-inspired design, neon green accents, and a dark theme.

## Live Demo

https://y-nayanasree.github.io/neon-tech-portfolio/

## Features

- Modern dark and neon-themed interface
- Responsive navigation bar
- About Me section
- Technical skills showcase
- Project portfolio cards
- Contact information
- Interactive navigation using JavaScript
- Mobile-friendly layout

## Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling, layout, and responsive design
- JavaScript – Interactive navigation behaviour

## Projects Featured

1. Autonomous Line Following Robot
2. Solar Power Generation Prediction
3. AI-Based Autonomous Drone Detection

## Repository Structure

```text
neon-tech-portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Deployment

This website is deployed using GitHub Pages.
